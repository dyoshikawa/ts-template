# Project Overview

- Manage runtimes and package managers with @mise.toml .
- AI tool configurations (`AGENTS.md`, `CLAUDE.md`, `.claude/`, `.github/instructions/`, …) are
  generated by [rulesync](https://github.com/dyoshikawa/rulesync) from `.rulesync/`. Never edit the
  generated files directly — edit `.rulesync/**` and run `pnpm generate`.
- When you want to check the entire codebase:
  - `pnpm cicheck:code` checks code style, type safety, and tests.
  - `pnpm cicheck:content` checks spelling and secrets.
  - `pnpm cicheck` checks both. Prefer this for daily checks.
- When doing `git commit`:
  - You must run `pnpm cicheck` before committing to verify quality.
  - You must not use here documents because it causes a sandbox error.
  - You must not use the `--no-verify` option because it skips pre-commit checks and causes serious
    security issues.
  - When creating a PR, you should include a link in the PR description that associates the PR with
    its issue.
- GitHub Actions must always be pinned to full-length commit SHAs. Run `mise run pinact` to pin them
  and `mise run pinact:check` to verify.
